# Privacy review

Answer each question with evidence from the change:
1. Which personal data does it collect, store, log, display or send (names, emails, IP addresses, identifiers, location, content)?
2. For each item: the purpose, the legal or product justification, and whether it is actually needed (data minimization).
3. Where it is stored, for how long, and how it is deleted.
4. Who can access it (users, operators, third parties); is access logged?
5. Does it leave the system or cross a region boundary?
6. Is any personal data written to logs, metrics or error messages? It shouldn't be.

## Output
A table: data item, purpose, storage and retention, access, shared with, verdict (ok or needs change). Then the required changes, if any. Never copy real personal data into the review.
