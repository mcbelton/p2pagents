# Operational insights

Use only the data given (ops summary, incidents, troubleshooting guides, architecture). Quote numbers.

1. Usage: who and what uses the system, how much, trends.
2. Health: availability against SLOs, latency, which monitors miss their objective.
3. Incidents: recurring failures, time to resolve, which were auto-fixed by TSGs, which needed a person.
4. Gaps: failures without a troubleshooting guide; monitors that are missing for important components.
5. Improvements: the 5 most valuable, each with expected impact, effort and the evidence behind it.
